# Heatmap SDK Reference

The `HeatmapService` is the SDK component that powers Spatial Intelligence. It runs server-side and automatically tracks player positions with spatial compression.

## Zero-Code Setup

```lua
local Upview = require(game.ServerScriptService.Upview)

Upview:Init({
    ApiKey = "upv_live_xxxxx",
    EnableHeatmaps = true,
}):Start()

-- Done! See Dashboard → Spatial Intelligence for results.
```

<Info>
  The SDK automatically discovers `UpviewAnchor` and `UpviewZone` tagged parts via `CollectionService`. No Lua scripting is required for basic spatial tracking.
</Info>

## Tagging System

### Anchors

Tag any `BasePart` with `UpviewAnchor` to enable object-space tracking:

| Property | Value | Required |
|----------|-------|----------|
| **Tag** | `UpviewAnchor` | ✅ |
| **Attribute** `UpviewContext` | String (e.g., `"Standard_House"`) | Optional (defaults to part name) |

When a player is within `HeatmapAutoAnchorDistance` studs (default: 200) of a tagged part, their coordinates are automatically converted to be relative to that part's `CFrame`.

### Zones

Tag any `BasePart` with `UpviewZone` to enable zone detection. The part's bounding box defines the zone boundary:

| Property | Value | Required |
|----------|-------|----------|
| **Tag** | `UpviewZone` | ✅ |
| **Attribute** `UpviewZoneName` | String (e.g., `"Lobby"`) | Optional (defaults to part name) |

## API Reference

### `Heatmap:SetPlayerEmotion(player, emotion)`

Set a player's emotion. All subsequent position samples include this emotion.

```lua
local heatmap = Upview:GetService("Heatmap")
heatmap:SetPlayerEmotion(player, "frustrated")
```

**Built-in emotions:** `happy`, `frustrated`, `excited`, `calm`, `confused`, `bored`, `neutral`

### `Heatmap:ClearPlayerEmotion(player)`

Remove a player's emotion (points will have `nil` emotion).

```lua
heatmap:ClearPlayerEmotion(player)
```

### `Heatmap:GetPlayerEmotion(player)`

Returns the player's current emotion or `nil`.

```lua
local emotion = heatmap:GetPlayerEmotion(player) -- "frustrated" or nil
```

### `Heatmap:RecordEvent(player, eventType, eventData?)`

Record a one-time spatial event at the player's current position.

```lua
-- Death event
heatmap:RecordEvent(player, "death", { cause = "fall" })

-- Purchase event
heatmap:RecordEvent(player, "purchase", { item = "Sword", price = 100 })

-- Custom interaction
heatmap:RecordEvent(player, "interaction", { target = "NPC_Shopkeeper" })
```

### `Heatmap:SetPlayerAnchor(player, anchor?, context?)`

Manually set or clear a player's anchor. Only needed if auto-anchoring is disabled.

```lua
-- Set anchor
heatmap:SetPlayerAnchor(player, workspace.House.Floor, "My_Custom_House")

-- Clear anchor
heatmap:SetPlayerAnchor(player, nil)
```

### `Heatmap:GetCurrentZone(player)`

Returns the zone name the player is currently in, or `nil`.

```lua
local zone = heatmap:GetCurrentZone(player) -- "Lobby" or nil
```

### `Heatmap:ForceFlush()`

Force-flush the point buffer immediately. Called automatically on shutdown.

```lua
heatmap:ForceFlush()
```

## Signals

| Signal | Parameters | Description |
|--------|-----------|-------------|
| `OnPointsCollected` | `{SpatialPoint[]}` | Fired when a batch of points is flushed |
| `OnZoneChanged` | `player, newZone, oldZone` | Fired when a player enters or exits a zone |
| `OnEmotionChanged` | `player, emotion` | Fired when a player's emotion is set |

## Configuration Options

```lua
Upview:Init({
    -- Required
    ApiKey = "upv_live_xxxxx",
    EnableHeatmaps = true,

    -- Tracking (all optional)
    HeatmapTrackingInterval = 2,       -- Seconds between samples
    HeatmapMinDistance = 0.5,          -- Min studs moved to record
    HeatmapMaxPointsPerFlush = 50,     -- Buffer size before flush

    -- Auto-Anchoring (all optional)
    HeatmapAutoAnchorEnabled = true,
    HeatmapAutoAnchorTag = "UpviewAnchor",
    HeatmapAutoAnchorDistance = 200,

    -- Auto-Zones (all optional)
    HeatmapAutoZoneEnabled = true,
    HeatmapAutoZoneTag = "UpviewZone",
})
```
