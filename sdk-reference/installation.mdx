The Upview SDK is a Luau ModuleScript that runs in your Roblox game. It collects player analytics, performance metrics, feedback, and error reports, then sends everything to your Upview dashboard.

This page covers how to install it and verify data is flowing.

## Prerequisites

Before installing, make sure:

- You have a Roblox game open in Roblox Studio
- You have an Upview workspace with an API key (get one at [dash.upview.dev](https://dash.upview.dev))
- **HttpService is enabled** in your game

<Warning>
  HttpService must be enabled or the SDK cannot send data. Go to **Game Settings → Security → Allow HTTP Requests** and turn it on.
</Warning>

## Installation

<Tabs>
  <Tab title="Studio Plugin">
    The Upview Studio plugin handles everything automatically. It fetches and installs the latest SDK files, creates the loader scripts, and validates your API key. It will tell you when a new SDK version is available whether it may be a bug fix, improvements or new features.

    <Steps>
      <Step title="Install the Plugin">
        Get the **Upview Plugin** from the [Roblox Creator Store](https://create.roblox.com/store/asset/105169432388186/UpviewPlugin).
      </Step>
      <Step title="Open the Plugin">
        Click the **Upview** button in the Plugins toolbar.
      </Step>
      <Step title="Enter Your API Key">
        Paste your API key from [your dashboard](https://dash.upview.dev). Your key starts with `uv_live_` or `uv_test_`.
      </Step>
      <Step title="Click Sync & Install SDK">
        The plugin will validate your key, install the SDK into `ReplicatedStorage`, and create a loader script in `ServerScriptService`. **This may take a few minutes for your first sync, due to roblox limitations.**

        <Warning>
          **Roblox Security Prompts**: When you first sync the plugin, Studio will show two permission dialogs, one for script access and one for network access to `sdk.upview.dev`. Click **Allow** on both. If the sync doesn't complete afterward, **restart Studio once** and try again. This is a known Roblox limitation with newly installed plugins.
        </Warning>
      </Step>
      <Step title="Test the Connection">
        Click **Play** in Studio. Check the Output window for `[Upview]` logs. Your dashboard will show the connection within a few seconds.
      </Step>
    </Steps>

    <Tip>
      The plugin automatically detects pushed updates up to the SDK and acts as a version control system, ensuring your game always runs the latest stable version without manual file replacement.
    </Tip>
  </Tab>
</Tabs>

## Minimal Working Example

This is the smallest script that gets data flowing. It's automatically injected by the Upview SDK.

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Upview = require(ReplicatedStorage.Upview)

Upview:Init({
    ApiKey = "uv_live_abc123...",
}):Start()
```

<Note>
  After calling `Init()` and `Start()`, the SDK begins collecting data automatically. You don't need to write any additional code for basic analytics or data.
</Note>

## What Gets Installed

```text
ReplicatedStorage/
└── Upview/
    ├── init.lua           -- Entry point (requires Core/Upview)
    ├── Core/
    │   ├── Upview.lua     -- Main SDK controller
    │   └── DataQueue.lua  -- Batching and HTTP pipeline
    ├── Services/
    │   ├── TelemetryService.lua   -- Metrics and error capture
    │   └── FeedbackService.lua    -- Feedback form system
    ├── Components/
    │   └── UIBinder.lua   -- Feedback form UI renderer
    └── Shared/
        ├── Types.lua      -- Type definitions
        ├── Signal.lua     -- Event system
        └── Utils.lua      -- Utility functions
```

## Common Mistakes

<AccordionGroup>
  <Accordion title="Plugin security prompts blocking sync">
    Roblox Studio shows two permission dialogs when the Upview plugin first runs:

    1. **"Allow UpviewPlugin to manage scripts"**, needed to create the SDK loader scripts
    2. **"Allow UpviewPlugin to access sdk.upview.dev"**, needed to download SDK files

    Click **Allow** on both. If the sync still fails or takes ages, **restart Studio**. Roblox sometimes doesn't apply plugin permissions until the next session. In rare cases, you may need to restart twice.
  </Accordion>

  <Accordion title="HttpService not enabled">
    If you see errors about HTTP requests being blocked, go to **Experience Settings → Security** and enable **Allow HTTP Requests**. This is off by default in new places.
  </Accordion>

  <Accordion title="Wrong API key">
    API keys start with `uv_live_` (production) or `uv_test_` (development). If you paste the wrong key, the SDK will log a warning and continue in offline mode meaning no data will reach your dashboard.
  </Accordion>

  <Accordion title="API key exposed on the client">
    Never put your API key in a LocalScript, ModuleScript in ReplicatedStorage that clients can read, or anywhere accessible from the client. The SDK handles server-to-client communication via RemoteEvents and the API key always stays server-side.
  </Accordion>

  <Accordion title="Calling SDK methods before Init">
    All SDK methods silently return if called before `Init()` and `Start()`. Make sure your init script runs before any other script that uses the SDK.
  </Accordion>
</AccordionGroup>

<Warning>
  Your API key must never be accessible from the client. The SDK handles client-side features (like feedback forms) through secure RemoteEvents, it does not expose the key.
</Warning>
